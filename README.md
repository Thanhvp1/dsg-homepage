# Đất Sài Gòn Café — Website Giao Diện

Giao diện trang chủ website cho thương hiệu **Đất Sài Gòn Café** — cà phê rang mộc truyền thống Việt Nam.

## 🌐 Xem trực tiếp
👉 **[https://thanhvp1.github.io/dsg-homepage](https://thanhvp1.github.io/dsg-homepage)**

## 📁 Cấu trúc
```
Web/
├── index.html          ← Trang chủ
├── style.css           ← Design System
└── assets/
    └── images/         ← Hình ảnh
```

## ✨ Nội dung trang chủ
1. Hero — Background + CTA
2. Giới thiệu thương hiệu
3. Khám phá dòng cà phê (Category)
4. Sản phẩm nổi bật
5. Câu chuyện Đất Sài Gòn
6. Giá trị thương hiệu
7. Kiến thức cà phê
8. Tin tức & Hoạt động
9. Hình ảnh / Social
10. CTA cuối
11. Footer

## 🎨 Design System
- **Font:** Public Sans + Playfair Display
- **Màu chính:** Đỏ `#CC1111` + Vàng `#D4930A`
- **Theme:** Light / Trắng theo thương hiệu ĐSG
- **Responsive:** Desktop → Tablet → Mobile
